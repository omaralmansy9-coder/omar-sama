## إضافة الأغنية
الموقع عليه شاشة باسورد في البداية، والباسورد الحالي هو `2462006`.

صفحة المشغل مضبوطة على اسم الأغنية: `حبيبي الأولاني` — `رامي صبري`.

للتشغيل الفعلي، ضع ملف الصوت الذي تملك حق استخدامه داخل مجلد `audio` باسم:
`our-song.mp3`

لم أضمّن ملف الأغنية نفسه داخل المشروع.

## رفعها على Vercel
1. اعمل Repository جديد على GitHub.
2. ارفع الملفات والمجلدين `images` و `audio`.
3. ادخل Vercel واختر Add New Project.
4. اختار الـ GitHub Repository.
5. Framework Preset: Other / Static.
6. Deploy.

ملاحظة: لا تعتمد على التشغيل التلقائي للصوت عند فتح الموقع؛ المتصفحات تمنع الصوت التلقائي غالبًا. هنا الصوت يبدأ بعد تفاعل المستخدم مع الصفحة.
